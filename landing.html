常見問題

關於雲端同步、私隱隔離同手機主畫面安裝的常見疑問。

使用 TransitDeck 需要收費嗎？

完全免費。網頁託管於 GitHub Pages，雲端資料庫採用 Firebase 免費額度，日常個人記錄幾千條影片封面都綽綽有餘。

朋友用同一個網址登入，會睇到我未出街嘅片嗎？

唔會。資料庫設有嚴格用戶隔離規則，每位用戶登入 Google 帳號後只能讀寫自己帳號下的資料夾，完全私密安全。

如果唔登入 Google 帳號可以用嗎？

可以。未登入時系統會自動以本機模式運作，資料儲存在你目前裝置的瀏覽器內，亦支援隨時匯出 JSON 備份檔案。

點樣將 TransitDeck 變成手機桌面 App？

喺 Android Chrome 或 iPhone Safari 打開網站後，按瀏覽器選單的「加到主畫面」或「安裝應用程式」，桌面就會出現專屬雙層巴士圖示。

上載電話影嘅高像素封面圖會唔會好慢？

唔會。系統喺上載前會自動喺本機將相片壓縮至 1280px 闊度，既保留清晰車牌同路線牌細節，又確保手機流動網絡秒速同步。

同步 YouTube 功能需要申請 API Key 嗎？

唔需要。只要輸入公開頻道的 Handle 或 UC 開頭 Channel ID，系統就會自動透過 RSS 介面讀取最新公開影片的標題與封面縮圖。
