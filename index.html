常見問題

關於 YouTube 自動儲存、模擬分類同雲端同步的常見疑問。

連接 YouTube 頻道後會重複儲存同一條片嗎？

唔會。系統會根據每條 YouTube 影片獨有的 Video ID 自動去重，已儲存過的影片不會重複建立，亦會自動配對片倉內的待上載紀錄。

模擬類影片（OMSI 2 / 報站機）點樣記錄？

新增紀錄時揀選「OMSI 2」或「報站機模擬」標籤即可，車牌欄位為選填，並提供常用地圖與報站機快捷標籤一撳填入。

朋友用同一個網址登入，會睇到我未出街嘅片嗎？

唔會。資料庫設有嚴格用戶隔離規則，每位用戶登入 Google 帳號後只能讀寫自己帳號下的資料夾，完全私密安全。

點樣將 TransitDeck 變成手機桌面 App？

進入片倉頁面後，喺 Android Chrome 或 iPhone Safari 選單按「加到主畫面」或「安裝應用程式」，桌面就會出現專屬雙層巴士圖示。

手動標記已上載時一定要填 YouTube 連結嗎？

唔一定。彈出輸入框時可以直接貼上連結（自動補齊縮圖），亦可以按「暫不填連結，直接標記」先更新狀態，日後隨時補填。

使用 TransitDeck 需要收費嗎？

完全免費，無需任何月費或 API Key 設定，打開即用。
