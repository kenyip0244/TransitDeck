# TransitDeck — 行車記錄片與模擬遊戲片雲端影片庫

**TransitDeck** 是一款專為拍巴士、鐵路行車記錄片，以及錄製 OMSI 2、報站機模擬遊戲片的創作者設計的雲端影片與封面管理工具（PWA）。支援手機、平板及電腦跨裝置即時同步，並可連接 YouTube 頻道自動讀取過往所有已發佈影片。

🔗 **線上使用網址**：[https://kenyip0244.github.io/TransitDeck/](https://kenyip0244.github.io/TransitDeck/)

---

## 核心功能

* **影片製作進度追蹤**：清晰劃分「未傳入電腦」、「已傳入待剪」、「已剪待上載」及「已上載 YouTube」四個階段，隨時掌握記憶卡與硬碟素材進度。
* **封面圖置頂核對**：支援直接上載手機拍攝的封面相片或遊戲截圖（自動於本機壓縮至 `1280px` 畫質以加快雲端同步），方便核對路線編號、電牌與車牌。
* **交通營運商與模擬遊戲分類**：內置九巴（KMB）、城巴（CTB）、龍運（LWB）、嶼巴（NLB）、港鐵（MTR）色標，並設有 **OMSI 2** 及 **報站機模擬（PIDS）** 專屬分類與常用地圖／車型快捷標籤。
* **YouTube 頻道全量自動讀取與儲存**：輸入公開頻道的 `@Handle` 或 `UC...` Channel ID，透過總上傳播放清單（`UU...`）與多重備援線路自動讀取過往全部公開影片並寫入影片庫（根據 Video ID 自動去重，不會重複建立）。
* **快捷狀態轉換與連結補填**：將待上載影片標記為「已上載 YouTube」時，可順便貼上影片連結並自動抓取高清縮圖補齊封面。
* **多維度排序與搜尋**：支援按拍攝／發佈日期（由新至舊、由舊至新）、影片名稱（A → Z / Z → A）及最近編輯時間排序，並可依關鍵字與類別即時篩選。
* **多用戶雲端隔離與 PWA 安裝**：透過 Firebase Authentication（Google 登入）與 Firestore 安全規則實現用戶資料完全隔離；未登入時亦支援本機離線儲存及 JSON 備份匯出／還原。
